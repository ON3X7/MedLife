# MedLife
Medlife é um sistema web voltado para a vida profissional e pessoal do médico, ele auxilia o usuário sobre como gerenciar o tempo, dinheiro e plantão, além de ajudar com dicas, ele possui ferramentas que auxiliam o usuário a atingir metas e sonhos. Tudo voltado para o usuário ser um bom profissional e ter uma boa qualidade de vida.
